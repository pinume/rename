# 资料整理工具

需要 Python 3.14+ 和 uv。在项目目录启动：

```sh
uv run main.py
```

uv 会安装项目及 Excel 读取依赖 `openpyxl`。菜单仅使用 `input()` 和 `print()`，也可通过 `uv run rename` 启动。

| 选项 | 功能 | 输入 |
| --- | --- | --- |
| 1 | 按品牌品类分类 | 资料目录、Excel 路径 |
| 2 | 导出 Markdown 目录结构 | 资料目录 |
| 3 | 汇总资料子文件夹 | 资料目录 |
| 4 | 按 Excel 序号重命名 | 资料目录、Excel 路径 |
| 0 | 退出 | — |

路径可包含空格和中文，可带成对的单引号或双引号，支持 `~`。四个功能独立执行，结束后返回菜单。`Ctrl+C` 或输入结束时退出。

## 分类与重命名

支持 `.xlsx`，读取“家电台账”工作表，第 2 行为表头。分类需要“交易参考号”和“品牌品类”，重命名需要“交易参考号”和“序号”。序号保留单元格的文本值（例如 `1-01`），不复现 Excel 的自定义数字显示格式。公式字段需要 Excel 已保存的计算结果。

分类只处理输入目录的直接子文件夹，将 `资料目录/交易参考号/` 移动到 `资料目录/品牌品类/交易参考号/`。

重命名递归查找交易参考号文件夹，将其改名为对应序号，位置和内部文件名保持不变。**先分类，再重命名**；重命名后的目录无法再用交易参考号匹配。

未匹配、空目标、存在不同目标值、非法文件夹名称、目标已存在或多个来源对应同一目标时，保留原目录并报告。重复 Excel 行的目标值相同则允许处理。

## 导出与汇总

导出递归列出子文件夹及其内部文件，按名称排序，保存为资料目录下的 `目录结构.md`；不列根目录直属文件。已有文件时输入 `y` 才覆盖。

汇总递归查找直接包含文件的末级子文件夹，将整个文件夹移动到 `资料目录/汇总/原文件夹名/`。排除已有的 `汇总`，保留移动后留下的空目录。遇到同名目标时跳过，不合并。**此功能以目录结构识别资料，目录中应只放要整理的资料子文件夹。**

所有扫描均忽略 `.DS_Store`，不进入符号链接目录；Markdown 也不列出符号链接。目标分类目录及 Markdown 文件不能是符号链接。

分类、汇总和重命名会直接改变原目录；发生错误时报告失败并继续其他项目，不自动回滚。操作期间请勿同时修改同一目录。

## 测试

```sh
uv run python -m unittest discover -s tests -v
```

测试使用临时目录及临时 Excel，不操作真实资料。
