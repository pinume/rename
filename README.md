# 资料整理工具

交互式命令行工具，用 CSV 台账分类、重命名资料文件夹，整理 POS 小票图片，并导出目录清单。仅使用 Python 标准库，无第三方运行依赖。

## 启动与操作

需要 Python 3.14+ 和 uv。在项目目录运行：

```sh
uv run main.py
# 或
uv run rename
```

1. 输入菜单编号。
2. 输入资料目录路径；选项 1–3 还需输入 CSV 路径，选项 6 可选输入核对 CSV 路径。
3. 按提示确认，完成后查看成功、跳过和失败信息，程序返回菜单。

路径支持中文、空格、`~` 和成对的单引号或双引号；相对路径以启动程序的工作目录为基准。输入 `0`、按 `Ctrl+C` 或输入结束时退出。

| 选项 | 菜单名称 | 处理范围与结果 |
| --- | --- | --- |
| 1 | 按品牌品类分类 | 直接子文件夹 → 品牌品类目录 |
| 2 | 按拨付批次分类 | 直接子文件夹 → 拨付批次目录 |
| 3 | 重命名为序号 | 递归匹配子文件夹，改为台账序号 |
| 4 | pos小票fmt | 递归整理图片名称，保留扩展名 |
| 5 | 汇总资料夹并清理空目录 | 第二层资料夹整夹移到资料根目录，删除空目录 |
| 6 | 导出名称并核对资料 | 第一层子文件夹 → `子文件夹名称.csv`；可选按 CSV 核对资料 → `缺少资料.csv` |

**需要分类时先分类，再重命名。** 分类依赖交易参考号文件夹名，改为序号后就无法按原交易参考号匹配。各功能独立执行，按需要选择。

### 执行确认与错误

- 选项 1–5 直接修改原目录，不保存操作日志或提供整体撤销。执行前显示资料目录，输入 `y` 才继续；大小写及首尾空白不影响确认，其他输入取消。操作期间保持该目录不被其他程序修改。
- 选项 6 的两个输出已存在时分别询问是否覆盖；确认规则相同。覆盖时先写入同目录的临时文件，完整写入后再替换原输出，写入或替换失败时原输出保持不变；输出正被 Excel 等程序打开时无法覆盖，提示关闭后重试。输出路径为符号链接时拒绝写入，即使确认覆盖也如此。
- 单个文件或文件夹移动失败会记录原因，继续处理其他项目；目录扫描或 CSV 读取失败会结束本次操作并显示错误。POS 小票命名（4）在处理中途扫描失败时停止，仍显示已完成的数量，并在失败详情中列出出错路径。已完成的修改保留，POS 图片的局部恢复规则见下文。
- 修改操作显示成功数量、跳过和失败详情。数量按实际移动或改名计数；POS 名称已符合结果时不计成功，被过滤的项目不一定出现在跳过列表中。

## 分类与序号重命名（1–3）

### 准备 CSV

每次读取一个 UTF-8、逗号分隔的 CSV，带或不带 BOM 均可，文件名不限。多个工作表需先合并为一张表，公式需导出为结果值。

| 选项 | 必需列 |
| --- | --- |
| 1 | `交易参考号`、`品牌品类` |
| 2 | `交易参考号`、`拨付批次` |
| 3 | `交易参考号`、`序号` |

一个 CSV 可同时包含以上各列，例如：

```csv
交易参考号,品牌品类,拨付批次,序号
T001,海尔电冰箱,第一批,001
T002,美的空调,第二批,002
```

- 自动寻找首个同时包含所需两列且列名各自唯一的表头行；列顺序不限，表头前可有说明和空行。
- 列名和字段仅去除首尾空白，交易参考号按文本精确匹配文件夹名。保留 CSV 中的前导零；导出 CSV 前已丢失的零无法恢复。
- 行尾缺少的字段视为空值，交易参考号为空的行忽略。含逗号或换行的字段需按 CSV 规则加引号。
- 先完整读取 CSV 再修改目录；非 UTF-8、引号格式错误或找不到有效表头时，本次不改动目录。

### 分类（1、2）

只检查资料目录的直接子文件夹，按台账移动整个文件夹：

```text
按品牌品类：资料/T001/ → 资料/海尔电冰箱/T001/
按拨付批次：资料/T001/ → 资料/第一批/T001/
```

已有分类目录继续使用；目标已存在时跳过，不合并。重复执行仍只检查第一层，已移入分类目录的资料不会被再次扫描；分类目录本身也参与匹配，通常报告“未匹配交易参考号”。

### 重命名为序号（3）

递归查找交易参考号子文件夹，改为对应序号，保留所在位置和内部文件名。例如 `资料/海尔电冰箱/T001/` 改为 `资料/海尔电冰箱/001/`；资料根目录本身不改名。

同一交易参考号对应多个不同的非空序号时，改为 `原交易参考号（序号异常）`，计入成功，供人工核对。已有同名异常标记时跳过。

### 冲突与无效值

以下情况保留原目录并报告跳过：

- 未匹配交易参考号、目标值为空，或同一交易参考号存在不同目标值；多个非空序号按上述异常标记规则处理。
- 目标名称为 `.`、`..`，或包含 `/`、`\`、`:`、空字符，例如 `2026/1/1`。
- 目标已存在、多个来源计划移动到同一路径、目标与来源相同或位于来源内部。
- 分类时目标分类目录本身也是待移动的资料文件夹，例如 `A → B/A` 同时 `B → C/B`；链式或循环关联的文件夹全部保留原位，其他文件夹照常分类。
- 目标父目录是符号链接。

重复台账行的目标值相同可正常处理；同一参考号同时出现一个非空目标和空目标时跳过。

分类和序号重命名均包含隐藏子文件夹，跳过符号链接目录。

## POS 小票命名（4）

递归处理资料根目录及子目录中的图片，仅改文件名，保留位置和扩展名。支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`、`.gif`、`.tif`、`.tiff`、`.heic`、`.heif`、`.avif`，扩展名匹配不区分大小写。

主文件名恰好为 `二合一照片`、`发票`、`IMEI`、`SN图片` 时保留原名；近似名称如 `发票截图` 照常改名。非图片、名称以 `.` 开头的文件和符号链接文件不改名；隐藏文件夹仍会进入扫描，符号链接目录不遍历。

每个目录独立编号：

- 文件名中的数字按数值排序；各扩展名分别编号，扩展名分组不区分大小写，输出保留原大小写。
- 依次使用最小可用编号：`POS小票.jpg`、`POS小票_2.jpg`、`POS小票_3.jpg`。
- 其他文件、文件夹或符号链接占用的名称会被跳过，占用检查不区分大小写；待处理图片的旧名称不算占用。
- 已有 `POS小票*` 图片也参与重新编号，例如仅有 `POS小票_8.jpg` 时改为 `POS小票.jpg`。最终名称与原名相同则不移动，重复执行结果稳定。

改名先暂存到同目录的 `POS小票临时_…`，再写入最终名称。暂存失败时尝试恢复该目录已暂存的图片，并跳过该目录；最终改名失败时保留已完成的结果，尝试恢复尚未完成的图片，其他目录继续处理。`Ctrl+C` 中断时也尝试恢复仍在临时名称的图片。恢复失败会报告文件实际所在路径。

## 汇总资料夹并清理空目录（5）

输入结构为 `资料/分类目录/资料夹/…`。以第二层资料夹为单位整夹移到资料根目录，保留其中所有文件的内容和相对路径，资料夹里只有子目录也整夹移动：

```text
资料/品牌甲/T001/补充资料/照片.jpg → 资料/T001/补充资料/照片.jpg
```

1. 完整扫描资料目录（含隐藏目录，不遍历符号链接目录），由深到浅删除实际为空的子目录，资料根目录保留。隐藏文件、`.DS_Store` 和符号链接都算目录内容。根目录下原有的空 `T001/` 因此会在移动前删除。
2. 移动清理后仍存在的第二层真实目录到 `资料/原资料夹名/`。多个来源同名时全部跳过；目标已被文件、目录或符号链接占用时跳过对应来源。分类目录里直接存放的文件保留原位。
3. 移动后删除已变空的分类目录。

执行前确认资料目录；结果分别显示成功移动的资料夹数和删除的空目录数。扫描失败时不改动目录；单项移动或删除失败会报告实际路径和原因，其余项目继续处理，已完成的移动保留，按报告处理剩余项。

整理后目录层级已改变，**不要直接重跑**：此时 `T001/补充资料/` 会被当作第二层资料夹再次移到根目录。资料目录中不要混放分类目录和已移出的资料夹。

## 导出名称并核对资料（6）

导出文件写入资料根目录，按名称的字符编码排序，不读取资料文件内容。

只列第一层子文件夹，不含根目录和符号链接，**包含隐藏文件夹**。输出 `子文件夹名称.csv`，仅一列，表头为 `文件夹名称`，使用带 BOM 的 UTF-8，供 Excel 显示中文。空目录只写表头。

### 核对资料完整性

名称导出后提示“核对 CSV 文件路径（回车跳过）”：

1. 回车跳过核对，返回菜单。
2. 输入 CSV 路径后选择匹配列：`1. 序号` 或 `2. 交易参考号`，无效选择重新输入。
3. 异常记录写入资料根目录的 `缺少资料.csv`，显示保存路径后返回菜单。

取消名称导出时不进入核对；取消核对结果覆盖时，已完成的名称导出保留。只检查 CSV 中列出的资料，没有对应记录的文件夹不出现在结果中。

匹配规则：

- CSV 要求同功能 1–3：UTF-8（带或不带 BOM），取首个所选列名唯一的表头行。
- 匹配值去除首尾空白后按文本精确匹配第一层子文件夹名，保留前导零；空值行忽略。包含隐藏文件夹，不含符号链接目录。
- 行尾缺少的字段补空；某行超出表头列数且多出的字段非空时报错，不生成结果。
- 文件夹不存在时记录 `缺少文件夹`。

文件夹存在时，只看直接存放的图片（扩展名同功能 4，不区分大小写），图片主文件名集合须恰好等于以下之一：

| 组合 | 图片主文件名 |
| --- | --- |
| 第一套 | `发票`、`POS小票`、`SN图片` |
| 第二套 | `二合一照片`、`发票`、`IMEI`、`POS小票` |

- 主文件名精确匹配；同名不同扩展名按一个名称计。缺少、多出或两套混用均为异常，没有图片按缺少处理。
- 隐藏文件、非图片文件、符号链接文件和下级目录不参与检查，不读取图片内容。

结果格式：

- 保留原表头、异常记录的全部字段和行顺序，重复记录各自保留；行尾补齐的空字段一并写出。
- 末尾追加 `缺少原因` 列；表头已有同名列时依次改用 `缺少原因_2`、`缺少原因_3`……
- 有 `二合一照片` 或 `IMEI` 时按第二套核对，否则按第一套核对。缺少原因直接列出与该套的差异，名称按字符编码排序，例如 `缺少 IMEI`、`缺少 POS小票，多出 POS小票_2`。
- 没有异常时只写表头。使用带 BOM 的 UTF-8；保留字段内容，不保证原引号写法或字节格式一致。
- 先读完 CSV 并检查全部文件夹再写入；读取或扫描失败时已有结果不变。核对 CSV 与 `缺少资料.csv` 为同一文件时拒绝执行。

## 测试与维护

```sh
uv run python -m unittest discover -s tests -v
```

测试使用临时目录及临时 CSV，不操作真实资料，覆盖分类、冲突、文件内容保留、POS 暂存恢复、导出格式、资料核对和交互菜单。
