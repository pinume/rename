# 资料整理工具

需要 Python 3.14+ 和 uv。在项目目录启动：

```sh
uv run main.py
```

uv 会安装项目及 Excel 读取依赖 `openpyxl`。菜单仅使用 `input()` 和 `print()`，也可通过 `uv run rename` 启动。

| 选项 | 功能 | 输入 |
| --- | --- | --- |
| 1 | 按品牌品类分类 | 资料目录、Excel 路径 |
| 2 | 按拨付批次分类 | 资料目录、Excel 路径 |
| 3 | 重命名为序号 | 资料目录、Excel 路径 |
| 4 | pos小票fmt | 资料目录 |
| 5 | 汇总资料子文件夹 | 资料目录 |
| 6 | 导出文件夹名称 | 资料目录 |
| 0 | 退出 | — |

菜单按整理流程排列：先分类（1、2），再重命名（3、4），最后汇总和导出（5、6）。

路径可包含空格和中文，可带成对的单引号或双引号，支持 `~`。各功能独立执行，结束后返回菜单。`Ctrl+C` 或输入结束时退出。

## 分类与重命名

支持 `.xlsx`，Excel 路径由用户输入，文件名和工作表名不限。分类需要“交易参考号”和“品牌品类”列，按批次分类需要“交易参考号”和“拨付批次”列，重命名需要“交易参考号”和“序号”列。各功能均自动查找各工作表中包含所需列的表头行，两列名称必须各自唯一，列顺序和表头行位置不限；多个符合条件的工作表合并匹配，冲突仍按异常处理。序号保留单元格的文本值（例如 `1-01`），不复现 Excel 的自定义数字显示格式。公式字段需要 Excel 已保存的计算结果。

分类只处理输入目录的直接子文件夹，将 `资料目录/交易参考号/` 移动到 `资料目录/品牌品类/交易参考号/`。按批次分类规则相同，移动到 `资料目录/拨付批次/交易参考号/`；已有批次目录会继续使用，同名目标跳过，不合并。重复执行时仍只扫描直接子文件夹，已归类资料不会再移动，批次目录本身会报告为“未匹配交易参考号”。

重命名递归查找交易参考号文件夹，将其改名为对应序号，位置和内部文件名保持不变。**先分类，再重命名**；重命名后的目录无法再用交易参考号匹配。

重命名时，同一交易参考号对应多个不同的非空序号，会将文件夹标记为 `原交易参考号（序号异常）`，保留位置及内部文件，计入成功数量，便于人工核对。

未匹配、空目标、分类存在不同目标值、非法文件夹名称（含 `/`、`\`、`:`，例如被 Excel 识别为日期的序号）、目标已存在或多个来源对应同一目标时，保留原目录并报告。异常标记的目标已存在时也会跳过，不覆盖。重复 Excel 行的目标值相同则允许处理。

## POS 小票图片

递归处理资料目录及各层子目录中的图片（`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`、`.gif`、`.tif`、`.tiff`、`.heic`、`.heif`、`.avif`，不区分大小写），改名为 `POS小票`，保留原扩展名和位置。主文件名恰好为 `二合一照片`、`发票`、`IMEI`、`SN图片` 的图片保持不变，近似名称（如 `发票截图`）照常改名。非图片文件、隐藏文件（以 `.` 开头，如外接盘上的 `._` 辅助文件）、文件夹名称和符号链接均不处理。

每个目录独立编号，按文件名排序，依次使用尚未被文件、目录或符号链接占用（不区分大小写）的最小编号：`POS小票.jpg`、`POS小票_2.jpg`、`POS小票_3.jpg`。已命名为 `POS小票` 或 `POS小票_N`（N 为不小于 2 且无前导零的整数）的图片保持原名，因此重复执行不会再改名。

## 导出与汇总

导出子文件夹名称只读取资料目录的第一层子文件夹（不递归、不含根目录，包含隐藏文件夹，忽略符号链接），按名称排序写入资料目录下的 `子文件夹名称.csv`。CSV 仅一列，表头为 `文件夹名称`，使用带 BOM 的 UTF-8，Excel 可直接显示中文；空目录只写表头。已有文件时输入 `y` 才覆盖。

汇总递归查找直接包含文件的末级子文件夹，将整个文件夹移动到 `资料目录/汇总/原文件夹名/`。排除已有的 `汇总`，保留移动后留下的空目录。遇到同名目标时跳过，不合并。**此功能以目录结构识别资料，目录中应只放要整理的资料子文件夹。**

所有扫描均忽略 `.DS_Store`，不进入符号链接目录。目标分类目录及导出的 CSV 文件不能是符号链接。

分类、按批次分类、汇总、重命名和 POS 小票命名会直接改变原目录；发生错误时报告失败并继续其他项目，不自动回滚。操作期间请勿同时修改同一目录。
