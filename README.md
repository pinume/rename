# 资料整理工具

需要 Python 3.14+ 和 uv，无第三方依赖。在项目目录启动：

```sh
uv run main.py   # 或 uv run rename
```

| 选项 | 功能 | 输入 |
| --- | --- | --- |
| 1 | 按品牌品类分类 | 资料目录、CSV 路径 |
| 2 | 按拨付批次分类 | 资料目录、CSV 路径 |
| 3 | 重命名为序号 | 资料目录、CSV 路径 |
| 4 | pos小票fmt | 资料目录 |
| 5 | 汇总资料子文件夹 | 资料目录 |
| 6 | 导出文件夹名称 | 资料目录 |
| 7 | 导出目录结构 | 资料目录 |
| 0 | 退出 | — |

菜单按整理流程排列：先分类（1、2），再重命名（3、4），最后汇总和导出（5–7）。**先分类，再重命名**：重命名后的目录无法再用交易参考号匹配。

## 通用规则

- 路径可包含空格和中文，可带成对的单引号或双引号，支持 `~`。
- 各功能独立执行，结束后返回菜单；`Ctrl+C` 或输入结束时退出。
- 选项 1–5 直接改变原目录且不留记录：执行前显示资料目录，输入 `y` 才继续，其他输入取消。发生错误时报告失败并继续其他项目，不自动回滚。操作期间请勿同时修改同一目录。
- 选项 6、7 的输出文件已存在时，输入 `y` 才覆盖，其他输入取消。
- 所有扫描均忽略 `.DS_Store`，不进入符号链接目录。目标分类目录和导出文件不能是符号链接。

## 分类与重命名（1–3）

CSV 要求：

- UTF-8、逗号分隔，带或不带 BOM 均可，路径由用户输入，文件名不限。
- 所需列：分类为“交易参考号”和“品牌品类”，按批次分类为“交易参考号”和“拨付批次”，重命名为“交易参考号”和“序号”。
- 自动查找首个同时包含所需列的表头行；两列名称必须各自唯一，列顺序和表头行位置不限，表头前可有说明和空行。
- 字段只去除首尾空白，按原文本使用，保留前导零（例如 `001`）；行尾缺少的字段视为空值。字段可含逗号和换行（需按 CSV 规则加引号）。
- 每次只读取一个 CSV：多个工作表需先合并为一张表，公式需先导出为结果值。CSV 导出前已丢失的前导零无法恢复。
- 编码不是 UTF-8、引号格式错误或找不到表头时提示错误，不改动目录。

分类只处理输入目录的直接子文件夹，将 `资料目录/交易参考号/` 移动到 `资料目录/品牌品类/交易参考号/`。按批次分类规则相同，移动到 `资料目录/拨付批次/交易参考号/`；已有批次目录会继续使用，同名目标跳过，不合并。重复执行时仍只扫描直接子文件夹，已归类资料不会再移动，批次目录本身会报告为“未匹配交易参考号”。

重命名递归查找交易参考号文件夹，将其改名为对应序号，位置和内部文件名保持不变。同一交易参考号对应多个不同的非空序号时，将文件夹标记为 `原交易参考号（序号异常）`，保留位置及内部文件，计入成功数量，便于人工核对。

未匹配、空目标、分类存在不同目标值、非法文件夹名称（含 `/`、`\`、`:`，例如 `2026/1/1`）、目标已存在或多个来源对应同一目标时，保留原目录并报告。异常标记的目标已存在时也会跳过，不覆盖。重复行的目标值相同则允许处理。

## POS 小票命名（4）

递归处理资料目录及各层子目录中的图片（`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`、`.gif`、`.tif`、`.tiff`、`.heic`、`.heif`、`.avif`，不区分大小写），改名为 `POS小票`，保留原扩展名和位置。主文件名恰好为 `二合一照片`、`发票`、`IMEI`、`SN图片` 的图片保持不变，近似名称（如 `发票截图`）照常改名。非图片文件、隐藏文件（以 `.` 开头，如外接盘上的 `._` 辅助文件）、文件夹名称和符号链接均不处理。

每个目录独立编号，按文件名排序（文件名中的数字按数值比较），各扩展名（不区分大小写，保留原大小写）分别依次使用尚未被其他文件、目录或符号链接占用（不区分大小写）的最小编号：`POS小票.jpg`、`POS小票_2.jpg`、`POS小票_3.jpg`。原名已是 `POS小票`、`POS小票_N` 或其他 `POS小票*` 的图片也会重新编号，例如目录中只有 `POS小票_8.jpg` 时改为 `POS小票.jpg`；最终名称与原名相同时不移动，因此重复执行名称保持不变。

改名时先将需要改名的图片移到同目录的临时名称（`POS小票临时_…`），再写入最终名称，避免互相占位或覆盖。暂存失败时恢复该目录已暂存的图片并跳过该目录；写入最终名称失败时恢复尚未完成的图片，无法恢复的报告其实际路径，其他目录继续处理。

## 汇总（5）

递归查找直接包含文件的末级子文件夹，将整个文件夹移动到 `资料目录/汇总/原文件夹名/`。排除已有的 `汇总`，保留移动后留下的空目录。遇到同名目标时跳过，不合并。**此功能以目录结构识别资料，目录中应只放要整理的资料子文件夹。**

## 导出（6、7）

导出文件夹名称只读取资料目录的第一层子文件夹（不递归、不含根目录，包含隐藏文件夹，忽略符号链接），按名称排序写入资料目录下的 `子文件夹名称.csv`。CSV 仅一列，表头为 `文件夹名称`，使用带 BOM 的 UTF-8，Excel 可直接显示中文；空目录只写表头。

导出目录结构递归列出资料目录下的全部文件夹和文件，写入资料目录下的 `目录结构.txt`（UTF-8），示例：

```text
资料/
├── 品牌A/
│   └── 001/
│       ├── POS小票.jpg
│       └── 发票.jpg
└── 说明.csv
```

首行为根目录名称，文件夹名后带 `/`。每层先列文件夹、再列文件，各自按名称（字符编码）排序。包含空文件夹和隐藏项，符号链接（包括指向文件的）一律不列出；根目录下的 `目录结构.txt` 本身不列出，子目录中的同名文件照常列出。名称中的换行、回车、制表符显示为 `\n`、`\r`、`\t`。不读取文件内容，不记录大小和时间；空目录只输出根目录名称。先完成扫描再写入，扫描失败时报告错误并保留已有文件。
